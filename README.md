# Muros que Hablan

Web del proyecto de mural participativo de la escuela Julio Montt Salamanca.

## Despliegue
Importar el repositorio en Vercel. Configuración: Other, sin comando de compilación, directorio de salida `public`.

## Inscripciones
Esta versión es una vista previa. El envío está deshabilitado hasta conectar una base de datos en línea y un servicio de correo. No contiene registros de participantes ni credenciales.
